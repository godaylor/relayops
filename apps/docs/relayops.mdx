RelayOps — самостоятельная модель управления инцидентами, а не переименование задач.
Основные экраны: Операции, Рабочий журнал, Доска реагирования, Комната инцидента,
Сервисы и Аналитика. Русский используется по умолчанию; RU / EN сохраняет выбор.

## Локальный запуск

Из корня репозитория с Node 24+ / pnpm 10.32.1:

```sh
pnpm local:prepare
pnpm local:up
```

Сайт: http://127.0.0.1:32000. PostgreSQL не опубликован на Windows,
Redis и SMTP для локальной демонстрации не требуются. Существующие volumes сохраняются.
Перед запуском проверьте занятость и Windows excluded port ranges:
`scripts/local/ports.ps1`. Подробности и альтернативный split-режим — в
`ENVIRONMENT_SETUP.md` корня репозитория.

## Первый инцидент

Создайте аккаунт, выберите создание **RelayOps** workspace, добавьте сервис,
затем создайте помеченный демоинцидент. Откройте журнал, сохраните представление,
проверьте переходы состояния на доске и опубликуйте запись в комнате инцидента.
Второй участник видит изменения через WebSocket; при переподключении выполняется
авторитетная загрузка из API. Конфликт версий не уничтожает черновик.

Аналитика сообщает выборку и исключения, а не выдаёт отсутствующие данные за нули.
Управление правами проверяется API независимо от видимости кнопок.
